# The Chronicles of Auld Ewe - Identity Forge

![Auld Ewe Banner](https://via.placeholder.com/800x200.png?text=Auld+Ewe+Character+Forge) *(Replace with actual banner image)*

**A mystical character generator for the *Chronicles of Auld Ewe* tabletop RPG**  
*Weave your destiny across seven planes of existence*

## 🌟 Features

### 🔮 Core Identity Generation
- **Dynamic Naming System** based on I Ching Hexagrams
- **Gender Selection**: Ram (♂) or Ewe (♀) archetypes
- **Shake-to-Roll** mobile functionality (iOS/Android)

### 🐑 Heritage System
- **14 Lineage Types**: From Pureblood Ewelings to Mechanized Tinkerweaves
- **20 Tribal Affiliations**: 
  - *Virtuous* (Lightbearers, Flamekin)
  - *Challenging* (Dread, Veilwalkers)
  - *Neutral* (Rootkin, Reverents)
- **Base Attribute Allocation** with Surplus Points

### 🌀 Inner World Matrix
- **Soul Patterns**: 12 mystical archetypes (Seeker of Trials, Lore Weaver)
- **Core Traits System**:
  - Conscious/Unconscious trait pairs
  - Hexagram-linked personality profiles
- **Character Journey Paths** with Age Band trajectories

### ⚡ Advanced Features
- **Hexagram Matrix** DC system (Intellectual/Physical/Emotional/Spiritual)
- **Telegram Integration** for character sharing
- **Session Tracking** with local storage
- **Device Motion API** for immersive interactions

## 🎮 Usage

1. **Gender Selection**  
   Choose between Ram (♂) or Ewe (♀) energy signatures

2. **Forge Identity**  
   Click the anvil button to generate:
   - Arcane Name
   - Lineage & Tribal Affiliation
   - Soul Pattern Matrix
   - Hexagram DC Values

3. **Advanced Options**
   - `Rename Character`: Refresh name while keeping lineage
   - `Shake Device`: Mobile-only random regeneration
   - `Send to Telegram`: Share character sheet via bot
